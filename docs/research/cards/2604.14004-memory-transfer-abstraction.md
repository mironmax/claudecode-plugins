# Memory Transfer Learning: How Memories are Transferred Across Domains in Coding Agents

arXiv [2604.14004](https://arxiv.org/abs/2604.14004) v1, 15 Apr 2026. KAIST, NYU, DeepAuto.ai.

**Claim.** A memory pool drawn from *other* coding benchmarks raises GPT-5-mini's
average Pass@3 across six benchmarks from 0.523 to 0.560 ("+3.7%", i.e.
percentage points) when memories are abstract Insights. The value transferred
is mostly meta-knowledge (inspect–edit–verify routines, guardrails).
Algorithmic strategy transfer accounts for 5.5% of the gains.

**Conditions.**
- Models: GPT-5-mini for everything (agent, memory writer, judge); DeepSeek
  V3.2 and Qwen3-Coder-480B for replication (+2.6, +1.8 points).
- Tasks: LiveCodeBench v6, Aider-Polyglot, SWE-Bench Verified,
  TerminalBench2, ReplicationBench, MLGym-Bench; at most 100 tasks each.
- Memory formats: Trajectory, Workflow, Summary and Insight, each generated
  once per trajectory by an LLM and never updated. Pool size is 431.
- Retrieval: top-3 by embedding similarity, placed in the system prompt at
  the start of the task only.
- Horizon: a single static pool; no stream, no updates.

**Applicability: partially.** The user-level graph is a cross-project pool,
and a principle-shaped node plays the same role as an Insight, so the
direction of the finding fits. The size of the effect is small, and the
isolating test is smaller still. Within Insights, task-agnostic memories beat
task-specific ones by 1.1 points (0.534 vs 0.523) on three benchmarks, with
no variance reported. The memories are procedural, while this store is mostly
declarative. The "negative transfer" from traces is per benchmark
(TerminalBench2 0.270 vs 0.315; MLGym 0.583 vs 0.667); on average,
Trajectory memory still beats zero-shot (0.534).

**What it would change here.** Testable, from existing logs: join
`useful.jsonl` to `recall.jsonl` on `kg_session`, then compare the
endorsement rate per surfacing for user-level nodes across projects. Do the
same for instance-shaped nodes (`core/utils.py:node_id_has_date`) versus the
rest. The paper predicts that undated, principle-shaped user nodes are
endorsed at a higher rate outside the project that wrote them. The paper's
own retrieval result (Table 7) is also relevant: LLM reranking (0.598) and
adaptive rewriting of retrieved memories (0.608) both trailed plain
similarity retrieval (0.630). That result does not support adding a rewriting
step at recall time.
