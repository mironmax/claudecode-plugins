# Continual Learning Bench: Evaluating Frontier AI Systems in Real-World Stateful Environments

arXiv [2606.05661](https://arxiv.org/abs/2606.05661) v1, 4 Jun 2026. Asawa et al., UC Berkeley.

**Claim.** Across six expert-validated domains, keeping the full history in
context (ICL) learns better than dedicated memory systems. The best system,
ICL on Claude Sonnet 4.6, captures 25.4% normalized gain over its own
stateless baseline. ACE on GPT-5.4 captures 8.6% at the highest cost ($62.8
per run).

**Conditions.**
- Models: Claude Opus 4.7, Sonnet 4.6, Gemini 3.1 Pro, Gemini 3 Flash, GPT-5.4.
- Tasks: codebase adaptation, database exploration, cohort studies, spectrum
  monitoring, sales prediction, poker. Some include a mid-stream variant
  switch (drift).
- Systems: full-context ICL, ICL Notepad (model-curated notes), Mem0 (top-10
  per step), ACE, and Claude Code and Codex headless with automatic
  compaction.
- Metric: gain, the stateful reward minus the same system's stateless reward
  on the same instance, normalized by headroom.
- Horizon: "on the order of tens of instances" per task; five rollouts.

**Applicability: partially.** The benchmark's horizon is short enough that
the full history fits in context. This plugin's horizon is months across
projects, where it does not, so "just use ICL" is not an available
alternative here. Two readings carry over. First, model-curated notes lose to
raw context on the same model: ICL Notepad on Sonnet 4.6 scores 3.5%
normalized reward and 18.2% gain, against 22.3% and 25.4% for ICL. Second,
"memory systems lose" is a statement about reward. On gain with GPT-5.4, Mem0
(20.2%) and ICL (20.1%) are level.

**What it would change here.** Its gain metric is the right shape for the
with/without benchmark listed under "Later" in the roadmap. That benchmark
needs paired stateful and stateless runs on the same instance, which logs
alone cannot supply. The stability/plasticity split (gain at the first
instance after a switch, versus gain within a variant) maps onto
project switches. It could be computed in a paired benchmark, not from
`useful.jsonl`.
