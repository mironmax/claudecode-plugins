# AgentCL: Toward Rigorous Evaluation of Continual Learning in Language Agents

arXiv [2606.02461](https://arxiv.org/abs/2606.02461) v2, 2 Jun 2026. Shu et al., OSU. *Addition to the starting corpus.*

**Claim.** Streams of loosely related tasks barely separate memory designs;
streams built so that earlier tasks are reusable later separate them clearly.
The cross-method standard deviation on CodeEval-Pro is 9.4 and 8.8 for
compositional streams, against 3.0 and 1.9 for naive ones. Methods with large
in-stream gains often show zero or negative stability, and fall below
memoryless on held-out tasks. For example, ExpRAG gains +17.7 in-stream but
+0.0 on stability and −4.2 on held-out; memoryless ReAct is best on held-out
at 72.5.

**Conditions.**
- Models: Qwen3.5-35B-A3B (default); gpt-oss-120b for deep research;
  Qwen3-Embedding-8B.
- Tasks: CodeEval-Pro (BigCodeBench-Lite-Pro pairs; HumanEval-Pro held out),
  BrowseComp+ (with LLM-synthesised subtasks), AgentBoard BabyAI and
  ScienceWorld, MMLU-Pro.
- Memory: LangMem, Mem0, AWM, Dynamic Cheatsheet, ExpRAG, ReMem, and the
  authors' MemProbe (interaction, insight and skill views, with an LLM judge
  filtering what is written). Top-2 retrieval throughout.
- Who writes, and when: after every task, without ground-truth feedback.
- Protocol: a read-write first pass, then a frozen read-only second pass,
  then held-out tasks. The gains are plasticity F−B, stability S−F and
  generalisation H−B.
- Horizon: 40 to 408 tasks per stream; three runs for coding.

**Applicability: partially; a methodology paper.** The held-out result bears
on cross-project recall at the user level. Memory built from weakly related
tasks "does not automatically transfer and may introduce mild interference."
The MemProbe ablation is also relevant: replacing its LLM write filter with
oracle feedback gives similar results (compositional 64.6/60.4 vs
66.7/64.6). By that ablation, an imperfect filter was enough in this setting.

**What it would change here.** For task 02: report replay results separately
for prompts whose terms overlap earlier sessions in the same project and for
prompts that do not. This is the log-side analogue of compositional versus
naive streams. Without the split, the paper's evidence predicts that
differences between ranking variants will be compressed toward zero.
